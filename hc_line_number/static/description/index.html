Line Number Widget

Add an automatic 1, 2, 3… position column to your one2many & many2many lists — with a single attribute

Odoo 18 OWL Zero Python Any Model

Why not just display the sequence field?

Odoo's drag handle stores arbitrary gaps in the sequence field — 10, 20, 30, or after a few reorders 3, 7, 41. Showing that raw value to users is confusing. What they actually want to see is the ordinal position of each row:

Features

True ordinal position

Displays 1, 2, 3… based on the row's actual position in the list — the stored value is never shown.

Live renumbering

Drag rows with the handle widget and the numbers update instantly. Add or remove a line — same thing.

Pagination aware

Page 2 continues where page 1 stopped: with 40 rows per page, the first row of page 2 shows 41.

One attribute, zero extra columns

Set widget="x2many_line_number" on the one2many / many2many field itself — no need to add sequence twice, or to have a sequence field at all.

Configurable header

The column header defaults to # and can be changed with options="{'line_number_string': 'Priority'}".

Pure OWL — zero Python

The widget is implemented entirely in JavaScript / OWL. No Python model changes, no stored data touched.

How to use

Set the widget on the x2many field itself (one2many or many2many) — the number column is inserted automatically, right after the drag handle:

<field name="group_ids" widget="x2many_line_number" options="{'line_number_string': 'Priority'}">
    <list>
        <field name="sequence" widget="handle"/>
        <field name="name"/>
    </list>
</field>

line_number_string is optional — the column header defaults to #. The widget is registered globally as x2many_line_number and becomes available immediately after installing the module.
